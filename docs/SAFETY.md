# Безопасность очистки и ремонта

Этот документ описывает, что именно меняет PURPLE RUSH, что остаётся нетронутым
и как откатить изменения. Он не заменяет точку восстановления Windows.

## Общие правила

- Все новые модули очистки выключены по умолчанию. Их нужно включить вручную.
- Перед основным запуском оптимизации создаётся точка восстановления.
- Разрушительные действия (`oldwindows`, `eventlogs`, сброс сети, сброс Windows
  Update, пересборка иконок) требуют отдельного подтверждения.
- Операции выполняются только от администратора; без прав они завершатся
  понятной ошибкой, а не «тихо» изменят систему.
- Программа не скачивает сторонние исполняемые файлы. SFC, DISM, CHKDSK,
  `pnputil`, `netsh`, `w32tm`, `wevtutil` — штатные компоненты Windows.
- RUST `exe`/`dll` не изменяются, в процесс игры ничего не внедряется.

## Что очищается

| Область | Пути / команды | Что не трогается |
|---|---|---|
| TEMP | `%TEMP%`, `%SystemRoot%\Temp` | файлы, занятые другими программами, пропускаются |
| Кэш обновлений | `SoftwareDistribution\Download`, `DeliveryOptimization` | установленные обновления и сама Windows |
| Дампы | `CrashDumps`, `Minidump`, `LiveKernelReports`, WER, `MEMORY.DMP` | рабочие документы пользователя |
| Браузеры | `Cache`, `Code Cache`, `GPUCache`, `ShaderCache`, Service Worker cache | пароли, история, закладки, cookie-базы |
| Steam / RUST | `logs`, `dumps`, `appcache\httpcache`, `*.dmp` | `cfg`, сохранения, настройки игры |
| Эскизы | `thumbcache_*.db`, `iconcache_*.db` | личные файлы; занятые кэши пропускаются |
| WinSxS | `DISM /Online /Cleanup-Image /StartComponentCleanup` | актуальные компоненты Windows |
| `Windows.old` | `Windows.old`, `$Windows.~BT`, `$Windows.~WS`, `$WinREAgent` | текущая установка Windows |
| Prefetch | `*.pf`, `ReadyBoot` | установленные программы |
| Журналы | `wevtutil cl` для включённых журналов | файлы приложений и личные данные |

Очистка браузеров может потребовать закрыть браузер: занятые файлы будут
пропущены, ошибка не появится.

## Ремонт Windows

| Инструмент | Риск | Комментарий |
|---|---|---|
| `SFC /scannow` | низкий | 5–20 минут; может потребоваться перезагрузка |
| `DISM /RestoreHealth` | низкий | 10–30 минут, нужен интернет |
| `DISM /StartComponentCleanup` | низкий | Windows может временно работать медленнее |
| `CHKDSK /scan` | низкий | онлайн-проверка без перезагрузки |
| Сброс Windows Update | средний | пересоздаёт `SoftwareDistribution` и `Catroot2`; нужна перезагрузка |
| Сброс сети | средний | Winsock/TCP-IP; сеть может пропасть до перезагрузки |
| WMI repair | средний | может потребоваться перезагрузка |
| Store reset | низкий | очищает кэш Store, приложения не удаляются |
| Пересборка иконок | низкий | перезапускает Explorer |
| Время / драйверы / Spooler | низкий | стандартные службы Windows |
| Точка восстановления | низкий | требует включённой защиты системы |

## Откат

- Модули оптимизации пишут исходные значения в `state.xml` и журнал; кнопка
  «ОТКАТ» возвращает реестр, службы, план питания, DNS и `cfg` RUST.
- Очистка файлов необратима: удалённые кэши и дампы не восстанавливаются.
- Сброс сети и обновлений откатывается перезагрузкой и повторной настройкой,
  а не кнопкой «ОТКАТ».
- Лучший полный откат — точка восстановления Windows, созданная перед запуском.

## Журналы

`%ProgramData%\RustOptimizer\rust-optimizer.log` содержит пути, коды выхода и
ошибки. Перед публикацией журнала удалите личные имена и пути.

## EAC

Программа не изменяет клиент RUST, не внедряется в процесс, не эмулирует ввод и
не использует оверлеи. Модули `cfg` работают с официальными файлами игры.
Полностью убрать траву официальными настройками нельзя — это меняет баланс.
Шейдеры и моды, вырезающие траву, не поддерживаются.
